# ☕ Java Completo: Do Zero ao Profissional - Projetos & Exercícios

> Repositório dedicado ao armazenamento, versionamento e acompanhamento do meu aprendizado no ecossistema Java, contendo exercícios práticos, desafios de programação e projetos desenvolvidos ao longo do curso.

---

## 🎯 Objetivo do Projeto

O objetivo principal deste repositório é consolidar a base teórica e prática do desenvolvimento em Java, transitando dos fundamentos da sintaxe até a criação de aplicações estruturadas. 

Por meio deste projeto acadêmico e prático, busco:
- Desenvolver um raciocínio lógico sólido para resolução de problemas computacionais.
- Aplicar os pilares da **Programação Orientada a Objetos (POO)** na prática.
- Construir um portfólio documentado que evidencie minha evolução técnica e o domínio de boas práticas de código.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Linguagem:** Java (JDK 17+)
- **IDE:** Eclipse / VS Code
- **Controle de Versão:** Git & GitHub
- **Paradigma:** Programação Orientada a Objetos (POO) e Programação Funcional

---

## 🧠 O que foi Aprendido com a Experiência

Durante o desenvolvimento dos módulos e projetos contidos neste repositório, adquiri e aprimorei os seguintes conhecimentos técnicos e práticos:

1. **Fundamentos e Estruturas de Controle:**
   - Manipulação de variáveis, tipos primitivos, operadores lógicos e condicionais.
   - Estruturas de repetição (`for`, `while`, `do-while`) para controle de fluxo eficiente.

2. **Programação Orientada a Objetos (POO):**
   - Abstração de problemas do mundo real em classes e objetos.
   - Aplicação prática dos quatro pilares: **Encapsulamento**, **Herança**, **Polimorfismo** e **Abstração**.
   - Construtores, métodos auxiliares, sobrecarga e visibilidade de membros (`private`, `protected`, `public`).

3. **Estrutura de Dados e Coleções:**
   - Uso de `Arrays`, `List` (`ArrayList`), `Set` e `Map` para manipulação e ordenação de dados em memória.

4. **Tratamento de Exceções & Boas Práticas:**
   - Criação e manipulação de exceções personalizadas com `try-catch-finally` para garantir a resiliência do código.
   - Organização de projetos em pacotes (*packages*) e nomenclatura padronizada (Clean Code).

5. **Versionamento de Código:**
   - Uso diário de Git para commits atômicos, gerenciamento de branches e rastreabilidade do histórico de desenvolvimento.
